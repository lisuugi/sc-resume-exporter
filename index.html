지원서 내보내기

삼성 커리어스에 작성한 내 지원서의 미리보기 화면을 Markdown 문서와 잘리지 않은 전체 이미지로 저장합니다. 설치할 프로그램 없이, 즐겨찾기 하나로 동작합니다.

데이터는 어디로도 전송되지 않습니다. 추출·변환·저장이 전부 사용자의 브라우저 안에서만 일어납니다. 서버가 없고, 분석 도구도 넣지 않았습니다. 이 페이지는 도구를 나눠 주는 안내문일 뿐이며 지원서 내용을 볼 수 없습니다.

설치

아래 버튼을 즐겨찾기 바로 끌어다 놓으세요. 한 번만 하면 됩니다.

지원서 내보내기 ← 이 버튼을 마우스로 끌어 즐겨찾기 바에 놓기

즐겨찾기 바가 보이지 않으면 Ctrl+Shift+B(Mac은 ⌘+Shift+B)로 켤 수 있습니다. 끌어다 놓기가 안 되는 브라우저라면 아래 콘솔에 붙여넣기를 쓰세요.

사용법

  1. 삼성 커리어스에 로그인하고 내 지원서 화면으로 이동합니다.
  2. 미리보기를 눌러 지원서 전체가 뜨는 창을 엽니다.
  3. 즐겨찾기에 넣어둔 지원서 내보내기를 클릭합니다. 화면 오른쪽 위에 작은 패널이 나타납니다.
  4. Markdown 추출 또는 전체 이미지 캡처를 누르면 파일이 바로 다운로드됩니다.

개인정보 마스킹을 체크하면 이름·주소·연락처·자격번호가 ███으로 가려진 사본이 만들어집니다. Markdown과 이미지 모두에 적용되며, 이미지는 캡처하는 순간에만 화면 글자를 바꿔 찍고 곧바로 원래대로 되돌립니다. 지원서 내용을 남에게 보여주며 첨삭을 받을 때 쓰세요.

이미지

미리보기 창은 안쪽에서만 스크롤되고 성적표는 가로로 잘려 있어서, 화면을 그대로 찍으면 취득학점·성적·재수강 여부 열이 사라집니다. 이 도구는 그 세 겹의 잘림을 모두 풀고 한 장으로 렌더링합니다. 세로로 아주 긴 JPG 한 장(대략 2400×20000px)이 나옵니다.

캡처 중에는 화면 배치가 잠깐 흐트러집니다. 작업이 끝나면 원래대로 되돌리며, 실패하더라도 복구는 실행됩니다. 불안하면 캡처 뒤 새로고침하세요. 저장하지 않은 입력이 있다면 먼저 저장해 두시길 권합니다.

개인정보

이 도구가 다루는 것은 지원자 본인의 이름·주소·연락처·학적·자격번호입니다. 민감한 정보이므로 설계 단계에서 외부 전송 경로를 아예 만들지 않았습니다.

항목내용
서버 전송없음. 네트워크 요청은 이미지 캡처 시 렌더링 라이브러리를 CDN에서 받아오는 것 하나뿐입니다.
저장없음. 쿠키·localStorage를 쓰지 않습니다.
추적없음. 분석 스크립트가 없습니다.
결과물사용자의 다운로드 폴더에만 저장됩니다.

다운로드된 파일에는 개인정보가 그대로 들어 있습니다. 공개 저장소나 커뮤니티에 올릴 때는 반드시 마스킹 옵션을 쓰거나 직접 지워 주세요.

알아두실 점

왜 웹페이지에서 바로 추출하지 않고 북마클릿인가요?

브라우저의 동일 출처 정책 때문입니다. 이 페이지는 삼성 커리어스와 다른 도메인이라 그쪽 화면 내용을 읽을 수 없습니다. 읽을 수 있다면 그게 오히려 심각한 보안 결함이고요. 추출 코드가 지원서 페이지 안에서 실행돼야 하므로, 그 코드를 즐겨찾기에 담아 사용자가 직접 실행하는 북마클릿 방식을 택했습니다. 대신 코드가 서버를 거치지 않으니 데이터가 새어 나갈 경로도 없습니다.

"지원서 미리보기를 찾지 못했습니다" 라고 나옵니다

미리보기 창이 열려 있지 않은 상태입니다. 지원서 화면에서 미리보기를 먼저 누른 뒤 다시 실행하세요. 미리보기가 열려 있는데도 같은 메시지가 나온다면 사이트 구조가 바뀐 경우이니 저장소에 이슈로 알려 주시면 고치겠습니다.

이미지 캡처가 실패하거나 아주 느립니다

지원서가 길면 렌더링에 수십 초가 걸립니다. 패널의 상태 문구가 "렌더링 중"이면 기다려 주세요. 사내망처럼 외부 CDN이 막힌 환경에서는 렌더링 라이브러리를 받지 못해 실패합니다. 이때 Markdown 추출은 외부 라이브러리 없이 동작하므로 그대로 쓸 수 있습니다.

표가 여전히 잘립니다

기본 캡처 폭은 1600px입니다. 표가 이보다 넓으면 도구가 캡처를 중단하고 경고합니다. 소스의 width 기본값을 키우면 해결됩니다. 이 경우도 이슈로 알려 주세요.

어떤 공고에서나 되나요?

미리보기 창의 구조(#formPreview)에 기대고 있으므로 같은 양식이면 동작합니다. 다만 검증은 특정 공고 하나에서만 이뤄졌습니다. 셀 병합이 있는 표는 정리를 건너뛰고 원본 그대로 내보내며, 값이 여러 개인 일부 필드는 | 로 이어 붙여 표기합니다. 결과물은 제출 전에 한 번 눈으로 확인해 주세요.

콘솔에 붙여넣어 실행하기 (북마클릿 대안)

지원서 미리보기를 연 상태에서 F12 → Console 탭에 아래 코드를 붙여넣고 Enter를 누르세요.

출처를 모르는 코드를 콘솔에 붙여넣는 것은 위험한 습관입니다. 이 코드는 저장소에서 전체를 읽고 확인한 뒤에 쓰시길 권합니다.

직접 고쳐 쓰기

전체 코드는 src/exporter.js 한 파일이며, 파싱 규칙과 그 근거는 docs/PARSING.md에 자세히 적어 두었습니다. 구조를 바꾼 뒤 npm test로 49개 검사를 돌려 확인할 수 있습니다. 

git clone https://github.com/lisuugi/sc-resume-exporter
cd sc-resume-exporter
npm install
npm test     # 파싱 로직 검증
npm run build  # 북마클릿 재생성
